# NUT reference data

These files come unchanged from [Network UPS Tools](https://github.com/networkupstools/nut)
and are licensed GPL-2.0-or-later, like NUT itself.

| File | Source | Used for |
|---|---|---|
| `cmdvartab` | `data/cmdvartab` | Descriptions returned by `GET DESC` and `GET CMDDESC` |
| `nut-names.txt` | `docs/nut-names.txt` | Tests that check the full-featured profile covers the whole naming spec |

To update, download the latest versions from NUT's master branch and rerun the simulator tests.
